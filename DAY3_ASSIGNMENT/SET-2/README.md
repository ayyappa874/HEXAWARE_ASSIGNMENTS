# Insurance Claims Portal – Set 2 (Ayyappa)

GitHub-ready assignment package for the Insurance Claims Portal Agile/Jira exercise.

## Contents
- `Insurance_Claims_Portal_Set2_Ayyappa.docx` – editable assignment document
- `Insurance_Claims_Portal_Set2_Ayyappa.pdf` – PDF copy
- `screenshots/` – six individual dark-mode screen images:
  1. Product Vision & Agile Comparison
  2. Epics & User Stories Backlog
  3. INVEST Review & Vertical Splitting
  4. Acceptance Criteria (Given / When / Then)
  5. Planning Poker Estimates & Backlog Size
  6. Definition of Done (DoD)

## Upload to GitHub
1. Create a repository, for example `Insurance-Claims-Portal-Set2`.
2. Extract this ZIP.
3. Upload the document files, this README, and the six images in `screenshots/`.
4. Commit the files to the repository.

## Screenshot note
The six individual images are separated from the final composed visual. They are illustrative Jira/Confluence-style screens, not live screenshots captured directly from an authenticated Jira account.
